# TariffTrail · Project Explorer

**Suggested title**
TariffTrail

**Short description**
Evidence-backed customs classification for similar U.S. cotton knitwear, with independent GenLayer validator review and finalized on-chain receipts.

**Project description**
TariffTrail helps importers and brokers document why similar products may need different tariff codes. The first rule pack compares U.S. cotton knit tops against official CBP ruling N350231. The GenLayer Intelligent Contract checks reported construction and cotton content, then uses independent validator consensus to match the product to a supported comparator or return an inconclusive outcome. A finalized receipt records the submitted observations, advisory six-digit code, official source, and evidence digest.

Open the dashboard and select the plain, slub, or incomplete demo to read actual Studionet state and export a receipt. To reproduce the workflow, load a sample, sign with the built-in Studio account, and paste the transaction hash into the dashboard to follow consensus. Ten offline tests and three finalized classification examples are included. Brokers verify recommendations against the current tariff schedule before filing.
